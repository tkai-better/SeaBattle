# Sea Battle (Bắn tàu)

Sea Battle là một trò chơi đối kháng dành cho hai người chơi. Trò chơi diễn ra trên các bảng lưới vuông (thường là 10x10) với các ô được định danh bằng chữ cái và chữ số. Mỗi người chơi sẽ sử dụng một bảng để đặt các chiến hạm của mình và một bảng để theo dõi các phát bắn sang vùng biển của đối phương.

## Bối cảnh dự án

Đây là bài tập giữa khoá của lộ trình Java Core do Ban Đào tạo ProPTIT chuẩn bị. Dự án nhằm giúp các bạn thành viên tổng hợp và áp dụng kiến thức sau 4 buổi học:
- Cú pháp Java cơ bản & Mảng 2 chiều.
- 3/4 tính chất cốt lõi của Lập trình hướng đối tượng (OOP).
- Thao tác quản lý mã nguồn cơ bản với Git.

## Tech Stack

- **Ngôn ngữ:** [Java](https://www.java.com/en/) (Java Core)
- **Công cụ quản lý:** Git & GitHub

## Hướng dẫn cài đặt và chạy thử

1. Clone repository về máy tính:
2. Mở dự án bằng IDE (IntelliJ IDEA, Eclipse, VS Code...).
3. Chạy file chứa hàm `main` để bắt đầu trò chơi.
*(Hoặc chạy trực tiếp thông qua file `BattleShip.bat` nếu không mở qua IDE)*
